# EventPrint

Stampe da eventi per i laboratori fotografici: il fotografo carica le foto,
i clienti le scelgono dal telefono, il negozio stampa. Zero costi di gestione.

## Prova la demo

Scarica **EventPrint-Studio-Demo.exe** dall'ultima release qui a destra:
un laboratorio fotografico inventato con tre eventi già pronti, ordini da
lavorare e la pagina cliente che si apre in locale. Niente da configurare,
niente account, niente installazione: si scarica e si avvia.

La demo è il prodotto vero con i dati finti: tutto quello che vedi funziona
così anche dal negoziante.
