# EventPrint

Stampe da eventi per i laboratori fotografici: il fotografo carica le foto,
i clienti le scelgono dal telefono, il negozio stampa. Zero costi di gestione.

## Prova la demo

**EventPrint-Studio-Demo.exe**, dall'ultima release qui a destra: un
laboratorio fotografico inventato con eventi già pronti, ordini da lavorare
e la pagina cliente che si apre in locale. Niente da configurare, niente
account: si scarica e si avvia.

## Hai una licenza? Scarica EventPrint Studio

**EventPrint-Studio.exe**, sempre l'ultima versione:
<https://github.com/bdbais/eventprint-beta/releases/latest/download/EventPrint-Studio.exe>

Al primo avvio importa il file di licenza `.eventprint` che hai ricevuto.
Senza licenza il programma funziona in versione di prova, un evento alla
volta.

Al primo avvio Windows SmartScreen può chiedere conferma: *Ulteriori
informazioni → Esegui comunque*.
